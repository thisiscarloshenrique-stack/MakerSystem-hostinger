========================================================
  SITE MAKER SYSTEM + LANDING PAGE VENDE+
  Como subir na Hostinger — passo a passo
========================================================

O QUE TEM NESTE PACOTE
----------------------
  index.html        -> o site principal (makersystem.com.br)
  vende-mais.html   -> a landing page do Vende+ (makersystem.com.br/vende-mais.html)
  img/              -> pasta com as logomarcas e os favicons
  LEIA-ME.txt       -> este arquivo (não precisa subir, mas não atrapalha)

IMPORTANTE: os três precisam ficar JUNTOS. Se você subir só os .html
e esquecer a pasta img/, as logos não vão aparecer.


ANTES DE COMEÇAR — GUARDE O QUE ESTÁ NO AR
-------------------------------------------
1. Entre no hPanel da Hostinger.
2. Vá em  Arquivos > Gerenciador de Arquivos.
3. Abra a pasta  public_html.
4. Marque os arquivos  index.html  e  vende-mais.html  que já estão lá.
5. Clique com o botão direito > Compactar (ou o botão "Compactar").
   Dê o nome  backup-site-antigo.zip
   -> Isso é o seu seguro. Se algo der errado, é só descompactar de volta.


SUBINDO OS ARQUIVOS NOVOS
--------------------------
6. Ainda dentro de  public_html, clique no botão de Upload (seta para cima).
7. Envie o arquivo  site-makersystem.zip  (o pacote que você recebeu).
8. Quando terminar de subir, clique com o botão direito nele >
   Extrair / Descompactar. Confirme extrair na própria pasta public_html.
9. Ele vai perguntar se quer substituir  index.html  e  vende-mais.html.
   Responda SIM (você já tem o backup do passo 5).
10. Confira que apareceu a pasta  img  dentro de  public_html.
11. Apague o  site-makersystem.zip  do servidor (já foi extraído, não serve mais).


CONFERINDO
----------
12. Abra  https://makersystem.com.br  no navegador.
    Se você ver o site antigo, é só cache: aperte Ctrl + Shift + R
    (ou Cmd + Shift + R no Mac) para forçar o recarregamento.
13. Abra  https://makersystem.com.br/vende-mais.html
14. Teste no celular também — as duas páginas se ajustam sozinhas.


SE ALGO DER ERRADO
------------------
Volte no Gerenciador de Arquivos, descompacte o  backup-site-antigo.zip
e o site volta a ser o que era. Nada é definitivo.


DEPOIS: COLOCANDO OS PRINTS DO SISTEMA
---------------------------------------
A landing page tem 4 espaços reservados para prints do Vende+ rodando.
Hoje eles aparecem como caixas cinzas escritas "[ print: ... ]".

Para trocar cada um por uma imagem de verdade:
  a) Tire o print da tela do sistema.
  b) Salve com o nome exato pedido na caixa:
        img/print-gatilhos.png    (a fila de contatos do dia)
        img/print-pdv.png         (o PDV ou a condicional)
        img/print-mensagem.png    (a mensagem pronta no WhatsApp)
        img/print-etiquetas.png   (entrada de XML / etiquetas)
  c) Suba os arquivos dentro da pasta  img.
  d) Me chame que eu troco o código dessas 4 caixas pelas imagens —
     é uma linha em cada uma.

Ou, mais simples: me manda os prints no chat que eu já devolvo
o vende-mais.html com eles no lugar certo.


O QUE MUDOU EM RELAÇÃO AO SITE ANTIGO
--------------------------------------
- O roxo saiu. O site principal agora usa o azul da logo Maker System
  e a landing usa o azul marinho + verde da logo Vende+.
- As logomarcas de verdade entraram no topo, no rodapé e no favicon
  (aquele ícone que aparece na aba do navegador).
- Todos os textos foram conferidos com medidor de contraste: nenhum
  texto do site fica abaixo do mínimo de legibilidade (WCAG AA).
- Nenhum botão ou link tem menos de 44 pixels de altura — dá para
  acertar com o dedo no celular.
- As páginas se adaptam ao modo escuro do celular/computador.
- Nada de fonte ou script baixado de fora: o site é 100% autossuficiente,
  então carrega rápido e não quebra se algum serviço de fora sair do ar.
